# Methodology

## Purpose

This directory contains the methodologies that guide how knowledge is acquired, researched, documented, and maintained throughout the Personal Knowledge Ecosystem (PKE).

Rather than focusing on specific subjects, these documents define the repeatable processes used to produce high-quality, consistent, and reusable knowledge.

---

## Methodologies

| Document | Purpose |
|----------|---------|
| `reading-methodology.md` | How books and other learning resources should be studied, annotated, and converted into knowledge. |
| `research-methodology.md` | Standard process for conducting research, evaluating sources, verifying information, and building evidence-based knowledge. |
| `documentation-methodology.md` | Standards for transforming research into structured, maintainable, and reusable documentation. |

---

## Guiding Principles

- Learn from reliable sources.
- Verify before documenting.
- Preserve existing knowledge before modifying it.
- Prefer clarity over complexity.
- Build reusable knowledge instead of isolated notes.
- Continuously refine knowledge as understanding improves.

---

## Status

This section will continue to evolve as the Personal Knowledge Ecosystem grows. The methodologies are intended to become the common operating procedures for all repositories in the ecosystem.
