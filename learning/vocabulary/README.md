# Vocabulary

A personal notebook for collecting useful words, phrases, idioms, and expressions encountered through reading, conversations, films, and everyday life. The goal is to gradually build a richer and more natural command of both English and Bengali.

## Structure

```text
vocabulary
├── README.md
├── bengali.md
├── english.md
└── phrases.md
```

## Collections

| Collection | Description |
|------------|-------------|
| **English** | Interesting words, advanced vocabulary, and useful expressions. |
| **Bengali** | Bengali words, literary expressions, and culturally significant terms. |
| **Phrases** | Everyday phrases, idioms, and conversational alternatives. |

## Purpose

- Build a stronger and more expressive vocabulary.
- Learn natural phrases and idioms used in everyday communication.
- Preserve interesting Bengali and English words discovered over time.
- Maintain a simple, searchable reference for quick revision and regular practice.
