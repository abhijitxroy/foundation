# Photography Projects

## Overview

This folder contains photography projects based on real-world experience.

Each project focuses on one photography situation, such as a beach, city, mountain, or night photography. The goal is to record what worked, what did not, and the lessons learned after each photoshoot.

## Project Structure

Each project should follow this structure:

```text
Project Name
├── Overview
├── Best Time
├── Camera Settings
├── Composition
├── Camera Angles
├── Common Mistakes
├── Editing
├── Lessons Learned
├── Best Photos
└── References
```

## Guidelines

- Keep notes short and practical.
- Add notes only after real photography sessions.
- Record camera settings that worked well.
- Record mistakes and how to avoid them.
- Update the notes as your photography skills improve.
