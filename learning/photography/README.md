# Photography

This section contains my personal photography and videography notes. It mainly focuses on iPhone photography while also covering the basic photography concepts that apply to any camera.

The goal is to build a simple and practical reference that I can quickly revisit before trips, photoshoots, or everyday photography.

The notes focus on practical techniques, camera settings, editing workflows, and useful lessons from real-world photography.
