# Thorium

Thorium is a naturally occurring radioactive element with atomic number **90**.

The most important naturally occurring isotope is **Th-232**.

## Basic Properties

| Property | Value |
|---|---|
| Element | Thorium |
| Symbol | Th |
| Atomic number | 90 |
| Main isotope | Th-232 |
| Nuclear classification | Fertile |

## Fertile, Not Fissile

Th-232 is **fertile**, not fissile.

It can absorb a neutron and eventually become fissile U-233.
