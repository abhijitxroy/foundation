# Engineering

A personal knowledge base for understanding how computers, software, and modern technology work from first principles. The goal is to build strong engineering fundamentals and preserve long-term knowledge through simple explanations, practical examples, and structured notes.

This section is designed to be beginner-friendly while remaining useful as a long-term reference and quick revision guide.

## Sections

|----------|-------------|
| **Computing** | Core computer fundamentals including hardware, memory, storage, and how programs execute. |

## Learning Path

| Stage | Topics | Objective |
|--------|---------|-----------|
| **1** | Computer Architecture, CPU, GPU, Memory, Storage | Understand how computers work internally. |
| **2** | Operating Systems, Processes, Threads, File Systems | Learn how software interacts with hardware. |
| **3** | Networking, Client-Server, Internet | Understand how systems communicate. |
| **4** | AI Foundations and PyTorch | Build a foundation for modern AI systems. |
| **5** | Data Structures, Algorithms, Databases | Learn the building blocks of software engineering. |
| **6** | Cloud, System Design, Security, Observability | Understand how production systems are designed and operated. |

## Design Principles

- Build knowledge from first principles.
- Keep explanations simple, practical, and easy to revisit.
- Learn concepts in dependency order.
- Prefer understanding **why** something exists before learning **how** it works.
- Connect theory with real-world engineering examples.
- Treat the repository as a long-term engineering knowledge system.

## Purpose

- Build strong engineering and computer science fundamentals.
- Understand how hardware, software, and networks work together.
- Learn modern AI and software engineering concepts from the ground up.
- Create a structured reference for continuous learning and quick revision.
- Develop a personal engineering knowledge base that can grow over a lifetime.
