# CPU (Central Processing Unit)

## What is a CPU?

The CPU is the **brain of a computer**. It executes instructions, performs calculations, and coordinates the work of all other hardware components.

In simple words:
- CPU decides **what to do**
- CPU processes **data and instructions**
- CPU manages the overall execution of programs

## What Does a CPU Do?

A CPU is responsible for:
- Running the operating system
- Executing applications
- Performing calculations
- Managing memory and input/output operations
- Coordinating communication between hardware components

## Key Components

| Component | Description |
|----------|-------------|
| **Core** | An independent processing unit inside the CPU. More cores allow more work to be done simultaneously. |
| **Thread** | A virtual execution path for a core. Some CPUs can run multiple threads per core. |
| **Cache** | Very small, extremely fast memory used to store frequently accessed data. |
| **Clock Speed** | The number of cycles the CPU can perform per second, usually measured in GHz. |

## CPU vs GPU

| CPU | GPU |
|-----|-----|
| Few powerful cores | Many smaller cores |
| Best for general-purpose tasks | Best for parallel processing |
| Optimized for low latency | Optimized for high throughput |
| Runs operating systems and applications | Accelerates graphics, AI, and large computations |

## Quick Summary

- CPU = Brain of the computer.
- Executes instructions and controls system operations.
- Uses powerful cores for complex and sequential tasks.
- Works together with components like memory, storage, and GPU to run applications.
