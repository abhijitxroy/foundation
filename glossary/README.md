# Glossary

A centralized collection of important terms, abbreviations, and definitions used throughout the repository. The glossary serves as a quick reference for both engineering and general knowledge topics.

## Structure

```text
glossary
├── README.md
├── abbreviations.md
├── engineering.md
└── general.md
```

## Collections

| Collection | Description |
|------------|-------------|
| **Engineering** | Technical terms and concepts related to computing, software, networking, AI, cloud, and system design. |
| **General** | Common terms from history, politics, economics, science, geography, and other non-engineering subjects. |
| **Abbreviations** | Frequently used acronyms and short forms across all domains. |

## Purpose

- Maintain a single source of truth for important terminology.
- Make notes easier to understand without repeatedly redefining concepts.
- Build a searchable reference for quick revision.
- Keep definitions concise, clear, and easy to revisit.
