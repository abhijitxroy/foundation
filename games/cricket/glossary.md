# Glossary

| Term              | Meaning                                                                                |
| ----------------- | -------------------------------------------------------------------------------------- |
| Batter            | Player who scores runs by hitting the ball.                                            |
| Bowler            | Player who delivers the ball to dismiss the batter.                                    |
| All-rounder       | Player who contributes with both batting and bowling.                                  |
| Wicketkeeper (WK) | Player who stands behind the stumps and performs catches, stumpings, and run-outs.     |
| Captain (C)       | Team leader who makes tactical decisions.                                              |
| Pitch             | The 22-yard strip where batting and bowling take place.                                |
| Wicket            | Three stumps and two bails; also refers to the dismissal of a batter.                  |
| Crease            | Marking on the pitch used for batting, bowling, and run-outs.                          |
| Boundary          | Edge of the playing field.                                                             |
| Over              | Six legal deliveries bowled by one bowler.                                             |
| Maiden Over       | An over in which no runs are scored from the bat.                                      |
| Innings           | A team's turn to bat.                                                                  |
| Run               | Basic unit of scoring in cricket.                                                      |
| Four              | Ball reaches the boundary after touching the ground.                                   |
| Six               | Ball crosses the boundary without touching the ground.                                 |
| Dot Ball          | A legal delivery from which no run is scored.                                          |
| Wide              | Illegal delivery outside the batter's reach.                                           |
| No Ball           | Illegal delivery that gives the batting team an extra run.                             |
| Bye               | Run scored without the ball touching the bat or the batter.                            |
| Leg Bye           | Run scored after the ball hits the batter's body (excluding the hand holding the bat). |
| LBW               | Leg Before Wicket dismissal.                                                           |
| Stumping          | Wicketkeeper dismisses a batter outside the crease.                                    |
| Run Out           | Batter is dismissed while attempting a run.                                            |
| Caught            | Batter is dismissed when a fielder catches the ball before it touches the ground.      |
| Bowled            | Ball hits the stumps and dislodges the bails.                                          |
| Hat-trick         | Bowler takes three wickets in three consecutive deliveries.                            |
| Century           | Batter scores 100 or more runs in one innings.                                         |
| Half-century      | Batter scores between 50 and 99 runs in one innings.                                   |
| Duck              | Batter is dismissed without scoring any runs.                                          |
| Powerplay         | Overs with fielding restrictions in limited-overs cricket.                             |
| DRS               | Decision Review System used to review umpire decisions.                                |
| Umpire            | Official who applies the Laws of Cricket and makes decisions during the match.         |
| Match Referee     | Official responsible for overseeing the conduct of the match.                          |
