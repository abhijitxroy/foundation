# Glossary

| Term              | Meaning                                                                              |
| ----------------- | ------------------------------------------------------------------------------------ |
| Board             | The 8 × 8 playing surface with 64 squares.                                           |
| Square            | One of the 64 individual spaces on the chessboard.                                   |
| File              | A vertical column on the chessboard (a–h).                                           |
| Rank              | A horizontal row on the chessboard (1–8).                                            |
| King              | The most important piece. The game is lost if the king is checkmated.                |
| Queen             | The most powerful piece on the board.                                                |
| Rook              | Moves horizontally and vertically.                                                   |
| Bishop            | Moves diagonally.                                                                    |
| Knight            | Moves in an L-shape and can jump over other pieces.                                  |
| Pawn              | The smallest piece that moves forward and captures diagonally.                       |
| Check             | The king is under immediate attack.                                                  |
| Checkmate         | The king is in check and has no legal move to escape.                                |
| Stalemate         | The player has no legal moves but is not in check. The game ends in a draw.          |
| Capture           | Taking an opponent's piece by moving onto its square.                                |
| Castling          | A special move involving the king and a rook.                                        |
| En Passant        | A special pawn capture performed under specific conditions.                          |
| Promotion         | Replacing a pawn with a queen, rook, bishop, or knight after reaching the last rank. |
| Opening           | The first phase of a chess game.                                                     |
| Middlegame        | The phase after the opening where most tactical and strategic play occurs.           |
| Endgame           | The final phase of the game when few pieces remain.                                  |
| Gambit            | An opening in which material is sacrificed for positional advantage.                 |
| Fork              | One piece attacks two or more opponent pieces at the same time.                      |
| Pin               | A piece cannot move because it would expose a more valuable piece behind it.         |
| Skewer            | A valuable piece is attacked and forced to move, exposing another piece behind it.   |
| Discovered Attack | Moving one piece reveals an attack by another piece.                                 |
| Zugzwang          | A position where any legal move makes the player's position worse.                   |
| Tempo             | A single move or the advantage gained by making useful moves.                        |
| FIDE              | Fédération Internationale des Échecs, the international governing body for chess.    |
| Grandmaster (GM)  | The highest title awarded by FIDE.                                                   |
| Elo Rating        | A rating system used to measure a player's playing strength.                         |
