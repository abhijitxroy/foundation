# Glossary

| Term            | Meaning                                                                                        |
| --------------- | ---------------------------------------------------------------------------------------------- |
| Assist          | The final pass leading directly to a goal.                                                     |
| Away Team       | The visiting team.                                                                             |
| Corner Kick     | Restart awarded when the defending team last touches the ball before it crosses the goal line. |
| Cross           | A pass played from the side of the field into the penalty area.                                |
| Dribble         | Moving the ball while maintaining control.                                                     |
| Extra Time      | Two 15-minute periods played if a knockout match is tied.                                      |
| Foul            | An unfair or illegal action against an opponent.                                               |
| Formation       | The arrangement of players on the field (e.g., 4-3-3, 4-4-2).                                  |
| Free Kick       | A kick awarded after certain fouls.                                                            |
| Goal Difference | Goals scored minus goals conceded.                                                             |
| Goal Kick       | Restart when the attacking team last touches the ball before it crosses the goal line.         |
| Goal Line       | The boundary line where the goal is placed.                                                    |
| Goalkeeper (GK) | The only player allowed to use hands inside their own penalty area.                            |
| Half-Time       | The break between the two halves of a match.                                                   |
| Handball        | Illegal use of the hand or arm to control the ball.                                            |
| Hat-trick       | Three goals scored by one player in a match.                                                   |
| Kick-off        | The method used to start or restart a match.                                                   |
| Offside         | A rule that prevents attackers from gaining an unfair advantage.                               |
| Penalty Area    | Area where the goalkeeper may handle the ball and where penalties can be awarded.              |
| Penalty Kick    | A direct shot taken from the penalty spot after a foul inside the penalty area.                |
| Red Card        | Player is sent off and cannot continue the match.                                              |
| Referee         | Official responsible for enforcing the Laws of the Game.                                       |
| Stoppage Time   | Extra time added to compensate for delays during play.                                         |
| Striker (ST)    | Main attacking player responsible for scoring goals.                                           |
| Throw-in        | Restart when the ball crosses the touchline.                                                   |
| Touchline       | The side boundary of the field.                                                                |
| VAR             | Video Assistant Referee, used to review important decisions.                                   |
| Yellow Card     | Official warning given to a player.                                                            |
