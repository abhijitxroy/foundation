# Growth

A collection of books on self-improvement, emotional well-being, resilience, habits, productivity, and personal development. The goal is to build a stronger mind, develop better habits, and create a balanced and meaningful life.

Each book has its own note containing chapter-wise summaries, important highlights, key ideas, and revision notes.

## Book Notes

Each book in this collection has (or will have) its own note file containing:
- Chapter-wise summaries.

## Purpose

- Build emotional resilience and self-awareness.
- Develop healthy habits and productive routines.
- Improve focus, discipline, and mental clarity.
- Learn practical approaches to personal growth and well-being.
- Maintain a personal knowledge base that can be revisited and expanded over time.
