# GPU (Graphics Processing Unit)

## What is a GPU?

The GPU is a specialized processor designed to perform **many similar calculations at the same time**. It was originally built for rendering graphics but is now widely used for AI, scientific computing, and video processing.

In simple words:
- GPU processes **large amounts of data in parallel**
- GPU speeds up graphics and compute-intensive workloads
- GPU works together with the CPU to improve overall performance

## What Does a GPU Do?

A GPU is responsible for:
- Rendering graphics and 3D scenes
- Accelerating video encoding and decoding
- Processing AI and machine learning workloads
- Running scientific and engineering simulations
- Performing large-scale parallel computations

## Key Components

| Component | Description |
|----------|-------------|
| **Core** | A small processing unit optimized for parallel work. GPUs contain hundreds or thousands of cores. |
| **VRAM** | High-speed dedicated memory used by the GPU to store graphics and computation data. |
| **Streaming Multiprocessor (SM/CU)** | A group of GPU cores that execute workloads together (name varies by vendor). |
| **Memory Bandwidth** | The speed at which data can be transferred between the GPU and its memory. |

## GPU vs CPU

| GPU | CPU |
|-----|-----|
| Many smaller cores | Few powerful cores |
| Best for parallel processing | Best for general-purpose processing |
| Optimized for high throughput | Optimized for low latency |
| Used for graphics, AI, and simulations | Used for operating systems and application logic |

## Quick Summary

- GPU = Parallel processing engine of the computer.
- Designed to perform many similar tasks simultaneously.
- Ideal for graphics rendering, AI, and large-scale computations.
- Works alongside the CPU rather than replacing it.
