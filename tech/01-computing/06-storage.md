

# Storage

## Overview

Storage is a computer system component responsible for permanently saving data, applications, operating systems, and user files. Unlike memory (RAM), storage retains information even when power is removed.

## Types of Storage

### Hard Disk Drive (HDD)

- Uses magnetic disks to store data.
- Provides large capacity at lower cost.
- Has slower access speed due to mechanical movement.

### Solid State Drive (SSD)

- Uses flash memory for data storage.
- Faster access time than HDD.
- No moving mechanical parts.

### NVMe Storage

- Uses PCI Express interface.
- Provides extremely high bandwidth and low latency.
- Commonly used in modern high-performance systems.

## Storage Performance Concepts

- Latency
- Throughput
- IOPS (Input/Output Operations Per Second)
- Sequential access
- Random access

## Storage Hierarchy

```
CPU Cache
    ↓
RAM
    ↓
SSD / NVMe
    ↓
HDD
```

## Storage in Modern Systems

Storage performance impacts:

- Database performance
- Application startup time
- Virtual machines
- Cloud infrastructure
- AI data pipelines

## Quick Summary

- Storage provides persistent data retention.
- SSD and NVMe offer faster performance than HDD.
- Storage performance depends on latency, bandwidth, and IOPS.
- Efficient storage design is important for scalable systems.
