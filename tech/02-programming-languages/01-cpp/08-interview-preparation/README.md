## Senior Engineer Thinking

Always ask:

1. Why was this design chosen?
2. Can this implementation scale?
3. Can production failures be handled gracefully?
4. Is the implementation maintainable?
5. Can the design be simplified?
6. What are the engineering trade-offs?
7. Will this approach work reliably in production?

### SMTS Thinking Model

Always try to think in three layers:

```text
Technical Impact
        ↓
Engineering Impact
        ↓
Business Impact
```

Whenever possible ask:

- Why was this introduced?
- What problem does it solve?
- What are the trade-offs?
- How does it impact production systems?
- How does it improve engineering productivity?
