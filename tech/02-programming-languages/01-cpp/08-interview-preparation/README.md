## Senior Engineer Thinking

Always ask:

1. Why was this design chosen?
2. Can this implementation scale?
3. Can production failures be handled gracefully?
4. Is the implementation maintainable?
5. Can the design be simplified?
6. What are the engineering trade-offs?
7. Will this approach work reliably in production?

## Semiconductor Interview Expectations

Interviewers may evaluate:

- Modern C++ Fundamentals.
- Production Engineering Practices.
- Memory and Concurrency Concepts.
- Debugging Abilities.
- Build Systems and Project Organization.
- Testing Strategies.
- Leadership and Collaboration Skills.
- Problem Solving Approaches.
- Production Quality Thinking.

The focus is usually less about memorizing definitions and more about explaining why particular engineering decisions were made.
