# Concept → Better Words (Easy English)

| Concept | Better Words |
|---------|-------------|
| Reference | refers to |
| Pointer | points to |
| nullptr | points to nothing |
| Reference | mandatory |
| Pointer | optional |
| const T& | read-only |
| T* | pointer to T |
| &T | Where is T? |
| *ptr | Give me the actual object |
| T* ptr | ptr is a pointer to T |
| *ptr = value | Change the actual object's value |

## Easy English Rules

- Reference → Something is mandatory.
- Pointer → Something is optional.
- `nullptr` → Nothing is available currently.
- `&object` → Where is the object?
- `T*` → Pointer to T.
- `*ptr` → Give me the actual object.
- `*ptr = value` → Change the actual object's value.

## Interview Rules

- Requirement first, syntax later.
- If something is mandatory → Think Reference.
- If something may or may not exist → Think Pointer.
- Keep answers simple and stop when the requirement is explained.
