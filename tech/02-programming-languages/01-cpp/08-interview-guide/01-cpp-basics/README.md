# C++ Basics Interview Guide

## Overview

This section covers interview questions related to the fundamentals of C++.

The objective is to build a strong foundation before moving to advanced Modern C++ topics such as RAII, Smart Pointers, Move Semantics, and Concurrency.

A solid understanding of these fundamentals is essential for writing correct, efficient, and maintainable C++ code.

---

## Topics Covered

- Why C++ Exists
- Compilation Process
- Variables
- References
- Pointers
- Const Correctness
- Functions
- Header Files
- Namespaces
- Classes & Objects
- Constructors
- Destructors
- Copy Constructor
- Assignment Operator
- Static Members
- Data Types

---

## Interview Focus

While preparing these topics, focus on:

- Explaining concepts clearly.
- Understanding why a feature exists.
- Comparing with Java where appropriate.
- Explaining the engineering problem being solved.
- Discussing performance implications.
- Using production-oriented examples instead of academic examples.

---

## Expected Outcome

After completing this section, you should be able to:

- Answer fundamental C++ interview questions with confidence.
- Explain concepts without relying on memorized definitions.
- Discuss design decisions using simple and clear language.
- Build a strong foundation for advanced Modern C++ topics.
