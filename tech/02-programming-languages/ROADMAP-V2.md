# Programming Languages Foundation Roadmap (V2)

## Philosophy

This roadmap prioritizes interview readiness and engineering depth over exhaustive language coverage. The primary goal is to build strong foundations in programming language concepts while emphasizing high ROI topics that are commonly encountered in senior engineering and platform engineering interviews.

Learning will follow five dimensions for every important topic:
- What is it?
- Why does it exist?
- How does it work?
- What is its engineering and production impact?
- How can it be asked in interviews?

---

## Learning Path

### Phase 1: Language Fundamentals (High Priority)

- Programming language design goals
- Compilation process and execution models
- Variables and data types
- Functions and namespaces
- References and pointers
- Header files and modularity concepts
- Classes, objects, constructors, and destructors
- Const correctness and language fundamentals

### Phase 2: Memory and Resource Management (Top Priority)

- Stack vs Heap memory
- Dynamic memory allocation concepts
- Resource management principles
- RAII
- Smart pointers
- Move semantics
- Rule of Three, Rule of Five, and Rule of Zero
- Memory leaks, dangling pointers, and undefined behavior

### Phase 3: Modern Language Features

- Templates and generics
- STL and common containers
- Algorithms and iterators
- Lambdas and auto
- Exception handling strategies
- Modern language features and best practices

### Phase 4: Concurrency and Runtime Concepts

- Threads and synchronization primitives
- Mutexes and locks
- Condition variables and atomics
- Runtime behavior and performance considerations
- Concurrency-related debugging concepts

### Phase 5: Build Systems and Ecosystems

- Build systems concepts
- Static and shared libraries
- Dependency management
- Package management concepts
- Development tooling and ecosystems

### Phase 6: Engineering and Production Thinking

- Debugging strategies
- Performance and scalability considerations
- Production problem-solving approaches
- Trade-off analysis and design decisions
- Technology selection strategies

---

## Learning Principles

For every topic, learning should progress through the following layers:

1. Beginner Level
   - Understand the basic concept.
2. Engineering Level
   - Understand why the concept exists and what problem it solves.
3. Production Level
   - Understand how it is used in real-world systems.
4. Interview Level
   - Understand common interview questions and trade-offs.
5. Senior Engineering Level
   - Connect technical decisions with engineering impact and system-level thinking.

---

## Goal

Build a strong foundation in programming languages by understanding language design, execution models, memory management, modern language features, and engineering trade-offs. The focus is on developing senior-level engineering reasoning, production-oriented problem-solving skills, and interview readiness rather than simply learning language syntax.
