# Networking Roadmap

## Objective

Build a strong understanding of computer networking as the engineering discipline that enables reliable, secure, scalable, and efficient communication between systems, applications, and users.

---

## Phase 1 — Networking Foundations

- What is Computer Networking?
- Network Types (LAN, WAN, MAN, PAN)
- Network Topologies
- Network Devices
- Data Communication
- Packet Switching

---

- OSI Model
- TCP/IP Model
- Layer Responsibilities
- Encapsulation & Decapsulation
- Protocol Stack
- Data Flow Across Layers

- IPv4 & IPv6
- Public vs Private IP

- Routing

---

## Completion Criteria

A topic is considered complete only when:

1. The concept is understood.
2. Practical exercises are completed.
3. The concept is applied in a real project.
4. Network behavior can be analyzed confidently.
5. The concept can be explained during a senior engineering interview.

---

## Learning Philosophy

Understand → Connect → Communicate → Secure → Optimize → Scale
