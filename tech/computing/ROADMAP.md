# Computing Foundation Roadmap

## Learning Path

### Phase 1: Computer Fundamentals

- Computer Architecture
  - Understand computer system components
  - Learn how CPU, GPU, memory, and storage interact

### Phase 2: Processing Units

- CPU (Central Processing Unit)
  - Instruction execution
  - Processor components
  - Sequential computation

- GPU (Graphics Processing Unit)
  - Parallel computing concepts
  - GPU architecture
  - AI and scientific computing workloads

### Phase 3: CPU vs GPU

- Compare CPU and GPU architectures
- Understand workload suitability
- Learn performance considerations


### Phase 4: Memory Systems

- Memory hierarchy
- RAM and cache concepts
- Data movement and performance impact

### Phase 5: Storage Systems

- Storage fundamentals
- SSD, HDD, and NVMe concepts
- Storage performance characteristics
- Persistent data and system storage design

### Phase 6: Program Execution

- Source code to executable flow
- Compilation concepts
- Operating system loading process
- Memory allocation and CPU execution
- Runtime interaction with hardware and system services

## Goal

Build a strong foundation in computer hardware concepts required for software engineering, system design, performance optimization, cloud computing, and AI engineering.
