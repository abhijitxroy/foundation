# Computing Foundation

## Overview

This module covers the fundamental concepts of computer systems, including processor architecture, CPU, GPU, CPU vs GPU comparison, memory systems, storage, and how programs are compiled, loaded, and executed.

## Learning Path

1. Computer Architecture
2. Central Processing Unit (CPU)
3. Graphics Processing Unit (GPU)
4. CPU vs GPU
5. Memory
6. Storage
7. How Programs Run

## Topics Covered

- Computer architecture fundamentals
- CPU components and instruction execution
- GPU architecture and parallel computing
- CPU and GPU workload differences
- Memory hierarchy and system performance
- Storage technologies, performance concepts, and data persistence
- Program compilation, loading, execution flow, and runtime interaction
