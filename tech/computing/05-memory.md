# Memory (RAM)

## What is Memory?

Memory, also called **RAM (Random Access Memory)**, is the computer's short-term working area. It temporarily stores the data and programs that the CPU is currently using.

In simple words:
- Memory holds data that is actively needed.
- It allows the CPU to access information quickly.
- Its contents are lost when the computer is turned off.

## What Does Memory Do?

Memory is responsible for:
- Loading the operating system and applications.
- Storing data that programs are currently using.
- Providing fast access to information for the CPU.
- Supporting smooth multitasking.

## Key Concepts

| Component | Description |
|-----------|-------------|
| **RAM** | Temporary, high-speed storage used while the system is running. |
| **Capacity** | The amount of data memory can hold (e.g., 8 GB, 16 GB, 32 GB). |
| **Speed** | How quickly data can be read from or written to memory. |
| **Volatile Memory** | Memory that loses its contents when power is removed. |

## Memory vs Storage

| Memory (RAM) | Storage (SSD/HDD) |
|--------------|-------------------|
| Temporary | Permanent |
| Very fast | Slower than RAM |
| Used by running programs | Used for long-term data storage |
| Data is lost after shutdown | Data remains after shutdown |

## Quick Summary

- Memory (RAM) is the computer's short-term workspace.
- It stores the data and applications currently in use.
- RAM is much faster than storage but is temporary.
- The CPU constantly reads from and writes to memory while executing programs.

## Conclusion

Memory is a fundamental component of computer systems that enables efficient data access, processing, and execution. Understanding memory hierarchy is essential for system design, performance optimization, and modern computing architectures.
