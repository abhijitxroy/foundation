# Software Quality

## Overview

Software quality determines whether a system consistently delivers correct, reliable, secure, maintainable, and valuable outcomes for its users. High-quality software is the result of disciplined engineering practices throughout the software lifecycle—not just testing at the end.

## Definition

Software quality is the degree to which a software system satisfies functional requirements, non-functional requirements, business objectives, and long-term maintainability expectations.

Quality is built into the engineering process rather than inspected into the product after development.

## Objectives

- Deliver reliable software.
- Reduce production defects.
- Improve customer satisfaction.
- Increase maintainability.
- Minimize operational risk.

## Quality Attributes

| Attribute | Description |
|-----------|-------------|
| Correctness | Meets functional requirements accurately. |
| Reliability | Performs consistently under expected conditions. |
| Performance | Responds efficiently under load. |
| Security | Protects systems and data from threats. |
| Maintainability | Supports safe modification and evolution. |
| Scalability | Handles increasing demand effectively. |
| Availability | Remains operational when needed. |
| Usability | Enables users to accomplish tasks efficiently. |
| Testability | Can be validated effectively through testing. |

## Engineering Practices That Improve Quality

- Clear requirements.
- Good software design.
- Coding standards.
- Code reviews.
- Automated testing.
- Static analysis.
- Continuous Integration.
- Observability.
- Root cause analysis.

## Common Mistakes

- Treating testing as the only quality activity.
- Measuring quality only by defect count.
- Ignoring technical debt.
- Skipping code reviews.
- Delaying quality checks until release.
- Failing to learn from production incidents.

## Interview Focus

Be prepared to explain how quality is engineered throughout the SDLC, how quality attributes influence architectural decisions, and how engineering practices reduce production risk.
