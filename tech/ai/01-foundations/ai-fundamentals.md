# AI Fundamentals

## Overview

Artificial Intelligence (AI) is a branch of computer science that focuses on creating systems capable of performing tasks that normally require human intelligence. These tasks include learning, reasoning, problem-solving, understanding language, recognizing images, and making decisions.

AI is a broad field that includes many specialized areas such as Machine Learning, Deep Learning, Natural Language Processing (NLP), and Computer Vision.

## What is Intelligence?

Intelligence is the ability to:
- Learn from experience.
- Understand and process information.
- Solve problems.
- Make decisions.
- Adapt to new situations.

Humans naturally perform these tasks. AI attempts to replicate some of these abilities using algorithms and data.

## What is Artificial Intelligence?

Artificial Intelligence is the capability of a machine or software system to mimic aspects of human intelligence. Instead of explicitly programming every possible action, AI systems can analyze data, identify patterns, and make predictions or decisions.

### Simple Definition

> AI is the science and engineering of building machines that can perform tasks requiring human-like intelligence.

## Goals of AI

The main objectives of AI are:
- Automate repetitive and complex tasks.
- Improve decision-making using data.
- Learn from experience and improve over time.
- Interact naturally with humans.
- Solve problems faster and more accurately.

## Types of Artificial Intelligence

### Artificial Narrow Intelligence (ANI)

Also called **Weak AI**, ANI is designed to perform a specific task. Almost all AI systems used today belong to this category.

Examples:
- Chatbots.
- Voice assistants.
- Recommendation systems.
- Image recognition systems.

### Artificial General Intelligence (AGI)

AGI refers to a theoretical AI system with human-level intelligence that can understand, learn, and perform any intellectual task a human can do.

Currently, AGI does not exist.

### Artificial Super Intelligence (ASI)

ASI is a hypothetical future AI that would surpass human intelligence in all fields, including creativity, reasoning, and scientific discovery.

## Rule-Based AI vs Learning-Based AI

| Feature | Rule-Based AI | Learning-Based AI |
|----------|---------------|------------------|
| Logic | Predefined rules | Learns from data |
| Adaptability | Low | High |
| Training required | No | Yes |
| Handles new scenarios | Poorly | Better |
| Example | Calculator, expert system | ChatGPT, image classifier |

## Major Branches of AI

### Machine Learning (ML)

Machine Learning enables systems to learn patterns from data instead of relying entirely on manually written rules.

### Deep Learning (DL)

Deep Learning is a specialized subset of Machine Learning that uses multi-layered neural networks to solve complex problems.

### Natural Language Processing (NLP)

NLP enables computers to understand, process, and generate human language.

Examples:
- Chatbots.
- Language translation.
- Text summarization.

### Computer Vision

Computer Vision allows machines to interpret and understand images and videos.

Examples:
- Face recognition.
- Object detection.
- Medical image analysis.

### Robotics

Robotics combines AI with physical machines to perform tasks in the real world.

Examples:
- Industrial robots.
- Autonomous drones.
- Self-driving cars.

### Expert Systems

Expert systems simulate the decision-making ability of a human expert using a large collection of predefined rules and knowledge.

## AI vs Machine Learning vs Deep Learning

| Feature | Artificial Intelligence | Machine Learning | Deep Learning |
|----------|------------------------|-----------------|---------------|
| Scope | Broad field | Subset of AI | Subset of ML |
| Learns from data | Sometimes | Yes | Yes |
| Uses neural networks | Optional | Sometimes | Core approach |
| Requires large datasets | Not always | Moderate | Often yes |
| Example | Chess engine | Spam filter | ChatGPT, image generation |

### Relationship

```text
Artificial Intelligence (AI)
            │
            └── Machine Learning (ML)
                    │
                    └── Deep Learning (DL)
```

## Key AI Terminology

| Term | Meaning |
|--------|----------|
| Data | Raw information used by AI systems. |
| Dataset | Collection of data used for training or testing. |
| Feature | An input variable used by a model. |
| Label | The expected or correct output. |
| Model | A mathematical representation learned from data. |
| Training | Process of teaching a model using data. |
| Inference | Using a trained model to make predictions. |
| Epoch | One complete pass through the training dataset. |
| Parameter | Internal value learned by the model. |
| Prediction | Output generated by the model. |
| Accuracy | Percentage of correct predictions. |

## Common Misconceptions

| Myth | Reality |
|-------|----------|
| AI can think like humans. | AI follows algorithms and learned patterns. |
| AI and Machine Learning are the same. | ML is a subset of AI. |
| AI always learns automatically. | Many AI systems are rule-based. |
| AI is always accurate. | AI models can make mistakes and inherit biases from data. |
| AI will replace all jobs. | AI is more likely to automate specific tasks while creating new opportunities. |

## Key Takeaways

- Artificial Intelligence is the broad field of creating intelligent machines.
- Machine Learning and Deep Learning are subsets of AI.
- AI systems learn patterns from data or follow predefined rules.
- Modern AI powers applications like chatbots, recommendation engines, and autonomous systems.
- Training teaches a model using data, while inference uses the trained model to make predictions.
- Most AI systems used today are examples of Artificial Narrow Intelligence (ANI).

## Quick Revision

- **AI** → Building intelligent machines.
