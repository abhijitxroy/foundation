# Machine Learning

## Overview

**Machine Learning (ML)** is a branch of **Artificial Intelligence (AI)** that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every possible situation.

Instead of writing fixed rules, developers provide examples (data), and the machine learning algorithm learns how to solve the problem.

Machine Learning forms the foundation for many modern AI applications, including recommendation systems, spam filters, fraud detection, image recognition, and Large Language Models (LLMs).

## Definition

> **Machine Learning is a method of teaching computers to learn from data instead of relying only on manually written rules.**

## Objectives

Machine Learning enables systems to learn patterns from data and make predictions or decisions without requiring explicit programming for every scenario.

Key objectives of Machine Learning include:
- Learn useful patterns from data.
- Build predictive and decision-making models.
- Automate complex tasks that are difficult to solve using fixed rules.
- Improve performance through experience and additional data.
- Enable intelligent applications across different domains.

## Types of Machine Learning

### 1. Supervised Learning

In supervised learning, the model learns using labeled data, where the correct answer is already known.

```text
Input Data + Correct Output
            │
            ▼
      Train Model
            │
            ▼
     Predict New Output
```

Examples:
- Email spam detection.
- House price prediction.
- Disease diagnosis.

### 2. Unsupervised Learning

In unsupervised learning, the model works with unlabeled data and tries to discover hidden patterns or groups.

```text
Input Data
     │
     ▼
Find Patterns or Clusters
```

Examples:
- Customer segmentation.
- Product grouping.
- Anomaly detection.

### 3. Reinforcement Learning

In reinforcement learning, an agent learns by interacting with an environment and receiving rewards or penalties.

```text
Agent
  │
  ▼
Take Action
  │
  ▼
Environment
  │
  ▼
Reward / Penalty
  │
  ▼
Learn Better Action
```

Examples:
- Game-playing AI.
- Robotics.
- Autonomous vehicles.

## Supervised vs Unsupervised vs Reinforcement Learning

| Feature | Supervised | Unsupervised | Reinforcement |
|----------|------------|--------------|----------------|
| Labeled data | Yes | No | No |
| Correct answers available | Yes | No | Reward signal |
| Goal | Predict outputs | Find hidden patterns | Maximize reward |
| Example | Spam filter | Customer clustering | Game AI |

## Common Machine Learning Algorithms

| Algorithm | Typical Use |
|------------|-------------|
| Linear Regression | Predict continuous values. |
| Logistic Regression | Binary classification. |
| Decision Tree | Rule-based predictions. |
| Random Forest | Ensemble classification and regression. |
| K-Means | Clustering similar data. |
| Support Vector Machine (SVM) | Classification tasks. |
| Neural Networks | Complex pattern recognition. |

> Deep Learning uses neural networks and is considered a specialized subset of Machine Learning.

## Machine Learning vs Deep Learning

| Feature | Machine Learning | Deep Learning |
|----------|-----------------|---------------|
| Feature extraction | Often manual | Automatic |
| Data requirement | Moderate | Large |
| Model complexity | Lower | Higher |
| Hardware need | CPU/GPU | Usually GPU/AI accelerators |
| Best for | Structured data | Images, text, audio, video |

## Quick Revision

- Machine Learning is a branch of Artificial Intelligence that learns patterns from data.
- The three major categories are supervised learning, unsupervised learning, and reinforcement learning.
- Training uses data to learn model parameters, while inference uses trained models to generate predictions.
- Machine Learning workflows include data preparation, model training, evaluation, deployment, and monitoring.
- Deep Learning is a specialized subset of Machine Learning based on neural networks.
- Modern AI applications such as recommendations, fraud detection, search, and Generative AI rely heavily on Machine Learning.
