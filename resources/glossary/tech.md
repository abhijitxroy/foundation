# Tech

This section contains foundational engineering and computer science knowledge. The goal is to build a strong understanding of how modern software and computing systems work, from low-level hardware concepts to large-scale distributed architectures.

## Structure

```text
engineering
├── ai

```

## Domains

| Domain | Description |
|---------|-------------|
| **AI** | Artificial intelligence, machine learning, deep learning, and related concepts. |
| **Application Architecture** | Software architecture, design patterns, and system design fundamentals. |
| **Cloud** | Cloud computing, virtualization, containers, and platform services. |
| **Computing** | Core computing concepts, CPU, GPU, memory, and hardware fundamentals. |
| **Databases** | Relational and NoSQL databases, storage engines, and data modeling. |
| **Networking** | Computer networks, protocols, internet fundamentals, and communication models. |
| **Observability** | Logging, monitoring, tracing, and debugging distributed systems. |
| **Operating Systems** | Processes, threads, scheduling, memory management, and OS internals. |
| **Programming Languages** | Language concepts, paradigms, runtimes, and compilation. |
| **Security** | Cybersecurity fundamentals, cryptography, authentication, and secure system design. |

## Purpose

- Build strong engineering fundamentals.
- Understand the principles behind modern software systems.
- Create a long-term, searchable reference for technical concepts.
- Organize knowledge in a way that supports continuous learning and quick revision.
