## Sections

| Section | Description |
|----------|-------------|
| `wishlist/` | Long-term learning goals, people to know, skills to develop, subjects to explore, and travel aspirations. |
| `books/` | Curated reading lists and lifetime book collections. |
| `films/` | Film watchlists and categorized movie collections. |
| `detective-stories/` | Detective, mystery, and adventure literature collections. |
| `vocabulary/` | Personal vocabulary notebook containing words, phrases, idioms, and language notes. |

## Purpose

The goal of this section is to build and maintain a lifelong personal knowledge base beyond engineering. It serves as a place to organize ideas, reading lists, watchlists, learning roadmaps, and reference material in a structured and searchable way.

## Design Principles

- Keep information simple and easy to revisit.
- Organize content by theme rather than chronology.
- Prefer curated collections over unstructured note dumps.
- Allow wishlist items to gradually evolve into dedicated study notes.
- Keep each topic in its own focused file whenever possible.
