# Finance

A collection of books on personal finance, investing, business, entrepreneurship, marketing, and wealth creation. The goal is to build practical financial knowledge and create a long-term roadmap toward financial independence.

Each book has its own note containing chapter-wise summaries, important highlights, key ideas, and revision notes.

## Book Notes

Each book in this collection has (or will have) its own note file containing:
- Chapter-wise summaries.
- Main ideas and highlights.
- Important frameworks and mental models.
- Quick revision notes.
- Personal observations and related books.

## Purpose

- Build a strong foundation in personal finance and investing.
- Learn the principles behind long-term wealth creation.
- Study business, entrepreneurship, and marketing.
- Understand the psychology behind money and decision-making.
- Maintain a personal knowledge base that can be revisited and expanded over time.
