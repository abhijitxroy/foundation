# Core

A collection of foundational books that are worth reading, studying, and revisiting over time. These books cover habits, thinking, communication, philosophy, psychology, learning, and personal growth.

Each book has its own note containing chapter-wise summaries, important highlights, key ideas, and revision notes.

| # | Book | Author | Difficulty | Theme | Status | Notes |
|:-:|------|----------|:----------:|--------|:------:|--------|
| 1 | Atomic Habits | James Clear | Basic | Habits | ⬜ | A good starting point. |
| 2 | Mindset | Carol S. Dweck | Basic | Psychology | ⬜ | Foundation for growth mindset. |
| 3 | Deep Work | Cal Newport | Medium | Focus | ⬜ | Read after *Atomic Habits*. |
