# Books

A personal knowledge library built around books that are worth reading, studying, and revisiting. The goal is not only to maintain a reading list, but also to preserve important ideas, chapter summaries, highlights, frameworks, and personal notes for long-term reference.

Each book has its own Markdown note, making this collection a living library rather than a simple catalogue.

## Collections

| Collection | Focus |
|------------|--------|
| **Core** | Foundational books on habits, communication, learning, philosophy, and personal growth. |
| **Finance** | Personal finance, investing, business, entrepreneurship, marketing, and wealth creation. |
| **Growth** | Self-improvement, emotional well-being, resilience, habits, and productivity. |
| **Mind** | Learning, psychology, critical thinking, philosophy, and understanding human behavior. |
| **Society** | Society, politics, ideology, propaganda, institutions, and the forces that shape public opinion. |

## How This Collection Works

- Each category has its own `README.md` with a reading roadmap and collection overview.
- Each book has a dedicated Markdown note for chapter-wise summaries and long-term knowledge capture.
- `book-note-template.md` provides a common structure for creating and maintaining book notes.
- Original PDFs or other reference materials can be stored separately and linked from individual book notes.

## Book Notes

A typical book note may include:

- Basic information about the book and author.
- Chapter-wise summaries.
- Main points and important highlights.
- Frameworks and mental models.
- Quick revision notes.
- Related books and authors.
- Personal observations and action items.
- References to physical copies, PDFs, or external resources.

## Purpose

- Build a personal lifetime reading roadmap.
- Preserve the most valuable ideas from important books.
- Organize knowledge by theme instead of maintaining an unstructured reading list.
- Connect ideas across finance, psychology, philosophy, business, history, and society.
- Create a long-term personal library that is easy to revisit, expand, and learn from.
