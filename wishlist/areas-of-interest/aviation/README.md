# Aviation

Aviation focuses on aircraft, flight operations, and the systems that enable safe and efficient air transportation.

## Topics

| Topic | Description |
|-------|-------------|
| Aircraft | Aircraft types, structures, and flight principles. |
| Air Traffic Control | Airspace management and aircraft guidance. |
| Helicopters | Rotorcraft design, operation, and applications. |
| Jets | Jet propulsion, fighter aircraft, and commercial jetliners. |
