# Computer Hardware

Computer hardware covers the physical components that form modern computing systems and their interactions.

## Topics

| Topic | Description |
|-------|-------------|
| CPU | Processor architecture and execution. |
| Motherboard | Core system board and chipset architecture. |
| Memory | RAM, cache, and memory technologies. |
| Storage | HDDs, SSDs, and storage interfaces. |
| GPU | Graphics processors and parallel computing. |
| Networking | Network hardware and communication devices. |
| Troubleshooting | Hardware diagnostics and problem resolution. |
