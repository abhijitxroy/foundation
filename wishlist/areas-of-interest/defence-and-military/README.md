# Defence & Military

Defence and military studies cover armed forces, military strategy, technologies, equipment, and national security.

## Topics

| Topic | Description |
|-------|-------------|
| Army | Land warfare and military organization. |
| Navy | Maritime operations and naval forces. |
| Air Force | Air power and aerial warfare. |
| Ranks | Military rank structures and command hierarchy. |
| Aircraft | Military aircraft and their operational roles. |
| Radar | Military radar systems and surveillance. |
| Sonar | Naval sonar systems and underwater detection. |
| Weapons | Conventional weapons and military equipment. |
| Missiles | Guided missile systems and strategic applications. |
