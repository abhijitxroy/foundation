# Maritime

Maritime studies focus on ships, navigation, ports, ocean transportation, and maritime operations.

## Topics

| Topic | Description |
|-------|-------------|
| Navigation | Maritime navigation principles and techniques. |
| Coordinate Systems | Marine positioning and geographic coordinate systems. |
| Ships | Ship types, construction, and operations. |
| Ports | Port infrastructure and logistics. |
| Tracking | Vessel tracking and maritime surveillance. |
| Maritime Law | International maritime regulations and legal frameworks. |
