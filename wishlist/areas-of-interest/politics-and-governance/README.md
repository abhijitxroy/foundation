# Politics & Governance

Politics and governance examine political systems, constitutional frameworks, public administration, and international relations.

## Topics

| Topic | Description |
|-------|-------------|
| Indian Politics | Political system and institutions of India. |
| Constitution | Constitutional principles and governance framework. |
| Parliament | Legislative processes and parliamentary structure. |
| Judiciary | Judicial system and rule of law. |
| Elections | Electoral systems and democratic processes. |
| International Relations | Relations between nations and global diplomacy. |
