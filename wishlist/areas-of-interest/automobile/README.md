# Automobile

Automobiles combine mechanical, electrical, and electronic systems to transport people and goods. This section serves as a roadmap for understanding modern vehicle engineering and maintenance.

## Topics

| Topic | Description |
|-------|-------------|
| Engines | Internal combustion and alternative powertrains. |
| Transmissions | Manual, automatic, CVT, and dual-clutch transmissions. |
| Suspension | Suspension systems, steering, and ride dynamics. |
| Braking | Braking systems, ABS, and braking technologies. |
| Electric Vehicles | EV architecture, batteries, motors, and charging systems. |
| Maintenance | Routine servicing, diagnostics, and preventive maintenance. |
