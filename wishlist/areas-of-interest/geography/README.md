# Geography

Geography explores Earth's physical features, environments, countries, and the relationships between people and places.

## Topics

| Topic | Description |
|-------|-------------|
| Maps | Reading and interpreting geographical maps. |
| Countries | Nations, capitals, and administrative divisions. |
| Rivers | Major rivers and river systems. |
| Mountains | Mountain ranges and geological formation. |
| Deserts | Desert ecosystems and climate. |
| Oceans | Oceans, seas, and marine geography. |
| Climate | Weather patterns and climate systems. |
| Time Zones | Global time standards and time zones. |
| Geopolitics | Geography's influence on international relations and strategy. |
