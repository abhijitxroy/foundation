# Wishlist

A collection of long-term goals, interests, and experiences that I want to pursue throughout my lifetime. This section acts as a personal roadmap for continuous learning, exploration, and self-improvement.

## Sections

| Section | Description |
|---------|-------------|
| Areas of Interest | Knowledge domains that I want to study in depth throughout my lifetime. |
| People & Personalities | Influential people whose lives, ideas, and achievements I want to study. |
| Reading | Reading goals, recommended books, and learning methodologies. |
| Skills | Practical skills that I want to develop through continuous practice. |
| Travel | Places I want to visit, travel planning, and experiences. |

## Purpose

This section helps me:

- Track lifelong learning goals
- Discover remarkable people and ideas
- Build practical skills beyond software engineering
- Maintain a reading journey
- Plan travel experiences
- Review progress periodically

## Structure

| File / Directory | Description |
|------------------|-------------|
| `areas-of-interest/` | Areas of knowledge and interest I want to explore in depth throughout my lifetime. Each area has its own dedicated, expandable knowledge space. |
| `skills-to-learn.md` | Practical skills and abilities I want to develop. |
| `reading-journey.md` | Reading goals, methodology, and curated book lists. |
| `figures-to-know.md` | Remarkable personalities whose lives and contributions are worth studying. |
| `travel.md` | Countries visited, travel wishlist, and travel philosophy. |

## Principles

- Focus on lifelong learning rather than collecting achievements.
- Prefer depth over breadth.
- Keep goals actionable whenever possible.
- Remove items once they are no longer relevant or completed.
- Review and update this list regularly.
